# web-file-explorer

一个基于 Python + Flask 的网页文件浏览器，可在浏览器里查看本机文件系统（受根目录限制），支持：

- 标签页 + 左右两栏布局（可同时打开多个页面，左侧文件夹浏览，右侧文件预览）
- 展示文件/目录列表
- 展示文件名、大小、修改日期
- 点击目录进入下一级
- 返回上级目录
- 按类型、名称、大小、修改日期排序（支持升序/降序）
- 文件名搜索过滤（空格分词，词与词之间是“与”关系）
- 地址栏下拉候选：第一个是“打开路径...”并弹出系统输入框，其余是手动打开历史（支持删除）
- 后退按钮：返回上一个访问路径
- 文件下载
- 常见文件预览：文本、图片、视频、音频（不支持类型会给出新窗口打开入口）
- 交互：文件夹双击进入，文件单击预览
- 可调显示参数（滑动）：图标大小、列数（1~8）、信息密度（低/中/高），默认收起，点击“展开显示设置”后显示
- 右键菜单：重命名、移动、复制、删除
- 文件夹右键可“添加到历史记录”
- 左右两栏中间分隔条支持拖动调整宽度
- 遇到无权限读取的子文件/子目录会自动跳过，不阻塞整个目录打开
- 页面整体固定不滚动，左右两个面板内部独立滚动
- 本地保存设置：图标大小、列数、信息密度、手动打开历史路径

## 运行方式

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

默认访问：`http://127.0.0.1:8000`

## 可选配置

可通过环境变量限制浏览范围根目录（默认 `/`）：

```bash
export FILE_BROWSER_ROOT=/home/yourname
python app.py
```

> 出于安全考虑，后端会拒绝访问 `FILE_BROWSER_ROOT` 之外的路径。
